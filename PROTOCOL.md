# Протокол v1
Заголовок 24 байта, struct `!BBH16sI`, big-endian. Смещения: version 0 (1 байт), type 1 (1), flags 2 (2), request_id 4 (16, UUID4 в бинарном виде), payload_length 20 (4). Далее ровно payload_length байт. Максимум 65536, проверка до накопления тела. Флаги: 1 ответ, 2 ошибка, 4 фрагментация (последние два зарезервированы). JSON UTF-8, корневой объект. Нулевое тело допустимо на уровне кадрирования, но не для JSON RPC. PING=1, PONG=2; остальные типы зарезервированы в Type (3–17). PING flags=0, PONG flags=1 с тем же request_id, объектом node и echo. Неожиданный ID, тип или флаг ответа отклоняется. Неизвестная версия/тип, превышение длины, повреждённый JSON, незавершённый кадр, тайм-аут и превышение квоты приводят к закрытию соединения. На этапе 1 ERROR не отправляется, причина записывается в журнал. Шифрование и фрагментация не реализованы.
